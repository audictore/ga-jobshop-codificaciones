# Algoritmo genético para job-shop: tres codificaciones

Actividad 05. Compara codificación binaria, permutación con repetición y llaves aleatorias para minimizar el makespan de un taller de maquinado (15 órdenes, 6 máquinas).

- `GaJobShop.cs`: código (C# 5, .NET Framework). Compilar con csc /r:System.Drawing.dll y ejecutar con la carpeta de salida como argumento.
- `resultados/`: CSV y gráficas.
- Informe en Word y PDF.
